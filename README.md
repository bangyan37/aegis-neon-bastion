AEGIS — Neon Bastion: an arena-defense roguelite in a single HTML file, no libraries, no assets, no network. Pilot the last Aegis fighter around the Bastion core at the centre of the arena and stop the swarm from reaching it. Three enemy classes (chasers, darts that hunt you, tanks that split when cracked) arrive in escalating waves, and every fifth wave a Warden boss circles the core with radial bullet bursts. Kills drop flux shards: collect them to level up and choose one of three upgrade cards — split cannons, ion lances, nova charges, core sutures, nanobot regen and more — so every run grows a different build. Full loop included: animated title screen, HUD with hull / bastion / flux bars, pause, game over with run stats and instant restart, particle bursts, screen shake, and a WebAudio synth soundtrack of bleeps made from raw oscillators. The game also renders deterministic seeded scenes for its screenshots (?shot=start|play|end).

## Run it

```sh
node --experimental-strip-types serve.ts
# then open http://localhost:8080 — WASD move, mouse aim, click or space to fire
```
